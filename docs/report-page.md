# 报告页的交互

[English](report-page.en.md) · [返回 README](../README.md)

`report.html` 是一个**自包含的静态文件**：CSS / JS / 数据全部内联，双击即开、不需要服务器，也不需要 Node。

## 页内播放 + 可点击时间戳

左侧固定一个吸顶播放器，配自建极简控制条（进度 / 时间 / 全屏）。页面里**每一个时间码都可以点**——点击即 seek 到对应秒数，播放中当前段落还会自动高亮。

时间点全部来自真实字幕段落，不是模型生成的：`render_report.py --strict` 会校验每个时间戳都不超出视频时长，超了直接报错、不出报告。

## 无干扰播放（护盾）

YouTube 自带的内嵌播放器会在暂停 / 结束时弹出自己的标题栏、频道行和「更多视频」推荐。这些元素来自跨域 iframe，**CSS 移不掉**。

报告的做法是在播放器上盖一层**常驻透明护盾**：它始终吞掉指针事件，让 YouTube 收不到 hover 事件，因此**播放过程中也不会弹出它的 chrome**。暂停 / 结束时护盾显形为封面（缩略图 + 播放键），右上角可以一键切回原画面。

## 全文朗读

标题下方的「朗读全文」按钮会**逐块朗读**全部栏目（结论 / 框架 / 观点 / 金句 / 冲突 / 热点 / 评论 / 译稿），当前块高亮并自动滚动。**双击正文任意段落即从该处起读。**

音源三选一，按可用度自动优选：

| 音源 | 需要什么 | 说明 |
|---|---|---|
| **微软 Edge 晓晓 Neural** | 在跑本地服务的机器上 `pip install edge-tts` | 免费、零密钥、最自然，**默认首选** |
| **豆包**（字节火山引擎） | 把 `scripts/tts_config.example.json` 复制为 `tts_config.json`，填 `appid` / `token` | 音质好，需要自己的密钥 |
| **浏览器原生 TTS** | 无 | 离线兜底，中文偏机械 |

中文时间戳会按「分 / 秒」朗读，例如 `07:20` 读作「零七分二十秒」。

## 播放自动化与本地服务

`render_report.py` 渲染结束后会**自动拉起本地预览服务**（`serve_report.py`，只绑 `127.0.0.1`），并输出一个 `preview_url`。通过这个地址打开报告，视频可以**页内直接播放**、时间码是真的 seek——因为它有合法的 origin，绕开了 `file://` 的限制。

这个服务同时充当**朗读的本地 TTS 代理**：

- 豆包密钥只经它转发，**不进 `report.html`、不进仓库**；
- 服务只监听回环地址，并且对 `/tts` 做了同源校验，其他网页无法跨域调用它。

## 离线单文件分享

`report.html` 自包含（只有视频和封面缩略图走 YouTube CDN），直接发给别人即可，无需服务器。

以 `file://` 打开时会自动降级：

- 显示封面，封面上给一个「本地预览」链接，点进去切到可页内播放的模式；
- 朗读降级为浏览器原生音源（因为没有本地代理了）。

## 播放器报错 150 / 101 / 153？

| 错误 | 原因 | 怎么办 |
|---|---|---|
| 150 / 101 | 视频作者禁止内嵌 | 时间点会自动改为在新标签页打开 `youtube.com/watch?v=…&t=…s`（带精确秒数） |
| 153 | 用 `file://` 直接打开了报告 | 用渲染时自动输出的本地预览链接打开，即可页内播放 |

以上都不会影响报告内容本身——只是播放方式从「页内」变成「新标签页」。

## 朗读没有声音 / 中文音色很机械？

按上表的优先级排查：先用 `pip install edge-tts` 拿到最自然的音源；没有本地服务时（`file://` 打开）只剩浏览器原生音源，中文确实偏机械。
