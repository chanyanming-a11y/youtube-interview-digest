▶ 看真实成品报告 GitHub 仓库

现场成品（Lenny's Podcast × Elizabeth Stone 示例）

下方为完整报告内嵌预览，点击任意时间码即可跳回原视频；也可 新标签页打开。

安装

git clone https://github.com/chanyanming-a11y/youtube-interview-digest.git
cd youtube-interview-digest
./install.sh                     # 自动探测你的 agent skills 目录并安装
./install.sh ~/.my-agent/skills  # 或显式指定任意支持 SKILL.md 的 agent 目录

依赖：Python ≥ 3.10，以及 pip install -r skills/youtube-interview-digest/requirements.txt（yt-dlp, youtube-transcript-api）。

怎么用

「帮我总结这个油管视频 https://www.youtube.com/watch?v=… 」
「精读 / 拆解这期播客，要带时间戳」
「这是某期访谈的字幕文件（.srt / .vtt / 带时间戳的 txt），帮我做精读」
