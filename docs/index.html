它和其他油管学习工具有什么不同

你不必精通英文，也不必有空看完整段视频。把一期 1–2 小时的油管访谈 / 播客丢给它，几分钟后得到一份中文精读：结论先行、每句都带可点时间戳、能一键跳回原视频原话。常见做法在这几件事上做不到：

时间戳真能跳回原话

别的工具给的总结里，时间码常常编错；这里每个时间点都取自真实字幕段落，超出视频时长直接报错、不出报告。

「原话」可信，不是编的

别的工具把嘉宾原话改写得面目全非；这里金句逐字比对原文，匹配不上就拒绝出报告。

不只给共识，也给锋芒

别的工具只复述大家都同意的；这里专门拆出观点冲突，连嘉宾和评论区的反驳都列出来。

知道观众真正在意哪段

别的工具看不到观众的关注点；这里结合回看热度与评论里的时间戳，标出热点与冷区。

产出你能自己留着

别的工具把结果锁在聊天框或某个平台里；这里是一份可离线分享的单文件 HTML，发给谁都行。

每期结果都一致

别的工具每次措辞都变；这里方法论写在文档里、脚本保证结构一致，换次跑也一样。

云 IP 环境（如本沙箱）会被 YouTube 整体封锁字幕接口，所以「抓取」这一步必须在你本机跑——其余翻译/解构/渲染仍在 agent 内： 

# 在你本机（正常 IP + 已登录 Chrome）一键抓全，把目录发回 agent 即可
./skills/youtube-interview-digest/local_fetch.sh "https://www.youtube.com/watch?v=eDFXtSg3zB8"

只有「抓取」需要联网；翻译、信号分析、解构、渲染都不需要。完整流程见 抓不到字幕怎么办。

安装（去平台化）

install.sh 不再绑定某个具体 agent：按「$1 → $SKILLS_DIR → 自动探测 $HOME/.*/skills（多候选取排序第一个）→ ~/.agent-skills」的顺序解析，安装前会打印实际落点。任何加载 SKILL.md 的 agent 都能对号入座。

git clone https://github.com/chanyanming-a11y/youtube-interview-digest.git
cd youtube-interview-digest
./install.sh                     # 自动探测你的 agent skills 目录并安装
./install.sh ~/.my-agent/skills  # 或显式指定任意支持 SKILL.md 的 agent 目录

依赖：Python ≥ 3.10，以及 pip install -r skills/youtube-interview-digest/requirements.txt（yt-dlp, youtube-transcript-api）。全文朗读最自然的音源需 pip install edge-tts（免费、零密钥）。
