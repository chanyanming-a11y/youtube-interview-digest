# 译稿规范（Step 2）

目标：产出 `transcript_zh.md`——**逐段保留时间戳**的中文译稿，既是后续解构的底稿，也会作为报告中的「全文译稿」被搜索和跟随播放。

## 输出格式（render_report.py 会按这个格式解析）

```
# 中文译稿 — <视频标题>

## Part 1 (00:00–10:00)
[00:00] Lenny：欢迎回到节目。今天的嘉宾是……
[00:31] Maya：说实话，路线图就是一个穿着计划外衣的猜测。
[01:02] Lenny：但领导层不需要日期吗？
```

- 每行 = `[时间戳] 说话人：译文`。说话人可省略，写成 `[时间戳] 译文` 也行。
- **时间戳必须和 `transcript.md` 里对应段落完全一致**（渲染时按时间戳挂回英文原文，偏差超过 3 秒就对不上）。
- 保留 `## Part N` 标题，方便分块处理。
- 不要合并段落、不要改时间戳；原文一段碎到只有几个词时，可以和下一段合译，但必须用前一段的时间戳。

## 说话人识别

- 带说话人分离的转写（例如来自 Substack 的外部转写）在 transcript.md 里以 `[mm:ss] Full Name: …` 开头。译稿里用简称，如「Lenny：」「Elizabeth：」。同一个人连续说话、被切成多段时，续段在 transcript.md 里不带名字，译稿里仍然要补上说话人。
- 自动字幕里的 `>>` 表示换人说话。结合上下文判断谁是主持人、谁是嘉宾：提问的通常是主持人，开场介绍里会出现嘉宾姓名。
- 在 `meta.json` 的 title / description / channel 里确认姓名。只能确认角色、确认不了名字时，写「主持人」「嘉宾」。
- 多人圆桌时写姓名，不要写 A/B/C。

## 翻译原则

1. **信 > 达 > 雅**。观点、数字、因果、限定条件（"大多数""在订阅业务里"）一个都不能丢。
2. **口语转书面，但保留语气**。删掉 "you know / like / I mean / sort of" 这类填充词和重复；保留强调、反问、自嘲这些态度信号，后面判断观点冲突要靠它们。
3. **术语统一**：第一次出现时写成「中文（English）」，比如「北极星指标（North Star Metric）」，之后只用中文。专有名词（公司、产品、人名、书名）保留原文，必要时加注。
4. **自动字幕纠错**：自动字幕常把专有名词听错（例如 "Figma" 识别成 "fig ma"，"Anthropic" 识别成 "and tropic"）。根据上下文改正后直接译，并在 digest 的 `glossary` 里记下这处更正。
5. **数字与单位**：保留阿拉伯数字，货币写成「2,000 万美元」这种中文写法；原话里的估算语气（"like 30%"）要译成「大约 30%」。
6. **金句预标记**：遇到可能成为金句的句子（观点鲜明、有画面感、反常识），在译文行末加 `⭐`。Step 3 挑金句时直接从 ⭐ 里选，**英文原句一律从 transcript.md 原样复制**。

## 长视频策略

| 时长 | 策略 |
|---|---|
| ≤ 60 分钟 | 全文逐段精译 |
| 60–150 分钟 | 逐段翻译，允许意译压缩（寒暄、广告、重复论述可以压成一句），但每段都要保留时间戳 |
| > 150 分钟 | 先读 `signals.md` 和章节，定位高热片段与核心章节做精译；其余段落做段落级摘译（一段一句），同样保留时间戳 |

分块执行：一次读一个 `## Part`（约 10 分钟，1,500–2,000 词），翻译完**追加写入** `transcript_zh.md`，再读下一个 Part。不要一次把全文读进上下文。

## 广告和赞助段

赞助口播（"This episode is brought to you by…"）译成一行 `[mm:ss] （赞助口播：品牌名，略）`，保留时间戳，不进后续分析。同一段口播被切成好几段时，每段都要保留一行（写成「赞助口播续，略」），保证时间戳一一对应。口播末尾如果接上了正题（比如主持人读完广告直接开始提问），这一行里要把正题部分译出来。

## 自检

写完后按时间戳和 paragraphs.json 逐条比对，确认两边的时间戳集合完全一致：

```bash
$PY - <<'EOF'
import json,re
P={p['ts'] for p in json.load(open('paragraphs.json'))}
Z={re.match(r'^\[([\d:]+)\]',l).group(1) for l in open('transcript_zh.md') if l.startswith('[')}
print('missing:',sorted(P-Z)); print('extra:',sorted(Z-P))
EOF
```
